Windows edition · Windows 10/11, 64-bit · no experience needed

From a brand-new Windows PC to a real, live app — step by step, start to finish.

One page, top to bottom. Set up the PC, build your first app, then add a real login, take a (test) payment, and put it on the internet. You won't write code — you'll ask the AI assistants in plain English, and they'll do the work and explain as they go.

🍎

Setting up a Mac instead? This page is for Windows PCs. The Mac walkthrough is on the home page — same idea, Mac commands.

🕒

Roughly how long: about 15–20 minutes of clicking, plus hands-off download time. With web-starter the downloads are small. If you pick full-stack or everything, the Android tools are a multi-gigabyte download that can run for a while in the background — that's normal, just leave it going (plugged in, on Wi-Fi). You can stop after any step — your work is saved as you go.

What you'll be able to build

🌐

Web apps

Modern sites and apps with React, Next.js, databases, and one-command deploys.

🎮

Games

2D/3D games in Godot or Unity, and browser games on the web.

📱

Phone apps

Real Android apps with Expo / React Native. (iOS versions build in the cloud or on a Mac — Apple only allows iOS builds on Macs.)

🤖

AI & ML

Run models locally with Ollama and LM Studio, explore in Jupyter — with GPU speed-ups on NVIDIA cards.

Make a free GitHub account if you don't have one — sign up at github.com. Your projects automatically back up to a private repo there, so your work is safe even if something happens to your PC. During setup, Claude does a one-time GitHub sign-in in your browser — just approve it when it asks.

🔌

Two quick checks for the install: be signed in to a Windows account that can approve installs (if a blue "Do you want to allow this app to make changes?" box appears, click Yes — that's normal), and plug into power (the downloads can run a while).

1Run one command

Open PowerShell — press the ⊞ Win key, type the word PowerShell, and press Enter. (On Windows 11 you can also right-click the Start button and choose Terminal.) PowerShell is just a text window where you type a command and the PC does it. In the window that opened, copy the command below with its Copy button, click anywhere in that window, paste with Ctrl+V, and press Enter:

Paste in PowerShell, then Enter 
irm https://raw.githubusercontent.com/zigrivers/mac-launchpad/main/bootstrap.ps1 | iex
⚠️

PowerShell just runs the command — it never explains it. You'll see lots of text scroll by, and that's it. If instead something gives you a breakdown of the command or offers to “explain before running,” the command went into the wrong place — usually the Windows search box, Copilot, or an AI chatbot — not PowerShell. Close that, click into the PowerShell window (the one with a blinking cursor after something like PS C:\Users\you>), paste, and press Enter.

This installs the essentials (winget packages, Git, the three AI assistants, and the setup files) and runs for a few minutes — lots of scrolling text is exactly what should happen. You'll know it's finished when the scrolling stops and it says “Foundation ready.” What do you call a computer that sings? A Dell.

💡

A blue “Do you want to allow this app to make changes?” pop-up during the run is an installer asking permission — click Yes.

🔒

Is it safe to run a command from the internet? This one is: it's the official setup script from this project's open, public repo (anyone can read it), and all it does is install standard tools, the three AI assistants, and the setup files. As a habit, only run irm … | iex from a project you trust — and you can always read it first.

To read it before running: download it, open it in Notepad, then run it.

Run in PowerShell 
irm https://raw.githubusercontent.com/zigrivers/mac-launchpad/main/bootstrap.ps1 -OutFile $HOME\bootstrap.ps1
notepad $HOME\bootstrap.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File $HOME\bootstrap.ps1

2Three quick logins

When the command finishes, close that window and open a new PowerShell window (same way as before) so the just-installed tools are ready to use — then do the rest of these steps in that new window. Sign into each assistant once: type the command, press Enter, and a browser window opens for you to log in.

✅

Only Claude Code is required to run the setup. Codex and Antigravity are optional — skip either if you like. You can always add them later.

↩️

Each command drops you into a chat with that assistant after you log in. When you're done logging in, type /exit (or press Ctrl+C twice) to return to the normal PowerShell line before starting the next one.

  1. Claude Code

    Type in PowerShell, then Enter 
    claude

    The very first time, Claude walks you through a few screens. Here's exactly what each one is asking for:

    1. Pick a colour theme. Claude shows a numbered list of styles. Dark mode is already selected — just press Enter to accept it and move on. (You do not type /exit here — that comes later.)
    2. Open the sign-in page. Claude tries to open your web browser by itself. If a browser doesn't pop up, press the c key to copy the long sign-in link it shows on screen, then paste that link into your browser with Ctrl+V and press Enter.
    3. Sign in with your Claude account in the browser. If it asks which kind of account, choose your Claude (Pro) one.
    4. Paste the code back. Once you've signed in, the browser shows a short code. Copy it, switch back to PowerShell, paste it where it says “Paste code here,” and press Enter.

    That's the login done — Claude drops you into a chat. Type /exit to return to PowerShell for the next one.

    🛡️

    You may see a red “Bypass Permissions mode” warning. Choose 2. Yes, I accept (press 2, then Enter). This lets Claude run the whole setup autonomously — each step without stopping to ask. It's fine to accept here because you're running the trusted Launchpad setup, and Git keeps checkpoints of your files so changes can be rolled back. Good habit: only accept “bypass” mode for a setup you trust — like this one.

  2. Codex

    Type in PowerShell, then Enter 
    codex

    Same pattern as Claude: choose “Sign in with ChatGPT,” sign in through the browser that opens, and paste any code back into PowerShell if it asks. Then return to PowerShell (/exit). If the browser doesn't open on its own, copy the link Codex prints and open it in your browser yourself.

  3. Antigravity

    Type in PowerShell, then Enter 
    agy

    It opens a Google sign-in in Chrome — sign in (pick a dark theme if asked), then return to PowerShell (/exit).

3Say “set me up”

Now hand the rest of the setup to Claude. Back at the normal PowerShell line, go into the setup folder and start Claude. (You exited Claude a moment ago just to finish signing in — now you reopen it inside the setup folder so it can run the install. cd means “change directory,” and ~ is your home folder.)

Type in PowerShell, then Enter 
cd ~\Developer\mac-launchpad
claude
📁

Only if you see “Cannot find path”: Step 1 didn't finish downloading the setup files. Run the Step 1 command again (it's safe — it continues where it left off and creates the folder), then retry the two lines above. Most people can skip this — go straight to the magic words below.

irm https://raw.githubusercontent.com/zigrivers/mac-launchpad/main/bootstrap.ps1 | iex

Claude is now running and waiting for you. Type this to Claude (not as a PowerShell command) and press Enter:

Type to Claude, then Enter 
Follow CLAUDE.md and set me up for everything.

CLAUDE.md is just the setup's instruction file — Claude reads it automatically, detects that this is a Windows PC, and runs the Windows setup. You never need to open it.

Claude will ask which kind of building you want to do, then install it. “Core” (the terminal, editors, and AI setup) always installs; the rest depends on what you pick:

📱

Phone apps on Windows build for Android. Apple only allows iOS builds on Macs — so your app's iOS version gets built in the cloud (the assistants can set that up with Expo's EAS service) or on a Mac. The app itself is one codebase either way.

4Watch it go green

Claude installs everything, then runs a health check and fixes anything that isn't right — repeating until every line is green. You don't have to do anything except watch, and step in when it asks. It will pause and tell you in plain English when it needs you — for example to approve a one-time login (like GitHub), or to click Yes on an install pop-up.

✅

“Green” means that tool is installed and working. When Claude says everything's green, your PC is a complete dev machine — you're ready to build.

🐳

One tool needs a single click from you: if you picked a profile that includes Docker (for databases and containers), open Docker Desktop once from the Start menu when Claude asks — it finishes its own setup on first launch.

5Build your first app

Setup just added handy shortcuts (like mkproj) to PowerShell. Open one fresh PowerShell window so they load, then make a safe project folder and start an assistant inside it:

Type in PowerShell, then Enter 
mkproj my-first-app
claude

Now Claude is running. Just describe what you want to Claude, like you'd tell a developer — the goal, not the how. For example, type this to Claude and press Enter:

Type to Claude, then Enter 
Build me a one-page site for my bakery with a menu, photos, and a contact form. Make it look warm and modern.

Claude will sketch a short plan, build it step by step, test it, open it in a browser to check it works, and show you the result. Don't like something? Say so — “make the button blue,” “add a dark mode.” It hot-reloads as it changes.

🧭

Expect a plan first. For anything non-trivial the assistants ask a few clarifying questions and plan before coding — so the first reply to “build X” may be questions, not code. That's intentional, and it produces better results.

Want the fully guided version? Follow Build your first app — the asking-for-a-build part works exactly the same on Windows.

6Add real features

This is where a toy becomes a real product. You don't run anything complicated — you ask the assistant, and it walks you through the one browser login each service needs and wires the code in for you.

🔐 Add a login

Say “add login to my app.” The assistant sets up Supabase, helps you create a free account, and scaffolds email-and-password sign-in: a login page and a members-only page that only signed-in people can see.

💳 Take a payment

Say “add payments.” The assistant sets up Stripe in test mode and scaffolds a pricing page → checkout → a “premium” page. Test with Stripe's card 4242 4242 4242 4242 — no real money moves.

🌍 Put it online

Say “deploy this so I can share a link.” The assistant uses Vercel — it links the project, securely pushes your keys, deploys, and hands you a live URL anyone can open.

💳

Payments stay in test mode. Build and try the whole checkout flow safely before any real charge is ever possible.

⚡

Just want to share something small right now — a page, an image, a PDF? Say “publish this to here.now” for an instant link, no account needed. (Anonymous links are public and last 24 hours.)

7Keep it safe & get unstuck

Everything you build is protected as you go:

☁️

Automatic backup. Each project is saved in Git (an unlimited undo button) and pushed to a private GitHub repo — a real off-machine backup. Ask any time: “save this and push my latest work.” If something breaks, say “undo the last change.”

🔒

Secrets stay secret. Never paste passwords or API keys into your code. The assistants keep them in a hidden .env.local file that's never published. A safety check scans every save and blocks anything that looks like a leaked key.

🐞

When something breaks. New apps are pre-wired for Sentry, which captures errors with the exact file and line. Just say “check Sentry and fix the error.”

Stuck on anything? Two things fix almost everything: paste any red text you see and ask “something went wrong — can you fix it?”, or check the troubleshooting page's Windows fixes.

🪟

Small print for Windows: a few of the Mac extras (launchpad report, the AI-spend tracker, the 1Password integration) aren't on Windows yet — ask an assistant in plain English for the same thing and it'll do it by hand. Everything on this page works today.
